## 关于这个仓库

站点源码。Astro 构建的单页静态站，无运行时依赖，push 到 `main` 后由 GitHub Actions 自动部署。

```bash
npm install    # 需要 Node >= 22.12
npm run dev    # http://localhost:4321
```

文案在 `src/data/site.js`，样式在 `src/styles/global.css`。
